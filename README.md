
# 🏠 California Housing Prices Analysis  

## 📌 Project Overview  
This project explores the factors influencing housing prices in California using data analysis and visualisation techniques.

The aim is to identify key variables that impact house prices and uncover patterns that could support better decision-making in the housing market.

---

## 🧰 Tools & Technologies  
- Python  
- Pandas  
- Matplotlib  
- Seaborn  

---

## ❓ Key Questions  
- What factors influence housing prices?  
- How does location affect property value?  
- Is income linked to house prices?  

---

## 🔍 Data Analysis Process  
- Cleaned and prepared dataset  
- Performed exploratory data analysis (EDA)  
- Visualised relationships between variables  
- Identified trends and correlations  

---

## 📊 Key Insights  
- Housing prices are strongly influenced by location and income levels  
- Areas with higher median income tend to have higher property prices  
- Some regions show significantly higher price growth than others  

---

## 💡 Recommendations  
- Buyers should consider location and income trends when investing  
- Policy makers can focus on high-demand areas for planning  
- Further analysis could include time-based trends for better forecasting  

---

## ✅ Conclusion  
This project demonstrates how data analysis can be used to understand housing market trends and support more informed decision-making.
